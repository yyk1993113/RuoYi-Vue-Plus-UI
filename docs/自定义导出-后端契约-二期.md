# 推广统计「自定义导出」二期后端契约

前端（`components/CustomExportDialog.vue` + `promoter.vue`）已把以下能力做成**扩展点**，未接后端时优雅降级、不报错。后端按本契约实现后，前端只需少量接线即可启用。

口径约定（与本仓运营台一致）：路径直写 `/admin/*`、**不补 `/api`**；接口 `@SaCheckRole("superadmin")`；租户/操作人由 `LoginHelper` 派生，前端不传。

---

## 1. 公共模板（管理员预设报表模板，全员可选用）— ✅ 已实现（前端 + 后端）

> 本节已落地，仅需在 IDEA 编译后端并执行建表 SQL。新增文件：
> - 后端：`RecExportTemplate`(domain) / `RecExportTemplateMapper`(mapper) / `IRecExportTemplateService` + `RecExportTemplateServiceImpl`(operation) / `AdminExportTemplateController`(/admin/recruitment/export-template)
> - 建表：`script/sql/ry_rec_export_template.sql`
> - 前端：`api/recruitment` 的 `listExportTemplates/saveExportTemplate/delExportTemplate`；`CustomExportDialog` 模板栏支持公共模板的选用/存为公共/删除。

表 `rec_export_template`：`template_id / tenant_id / scene / name / config(JSON longtext) / is_public(0/1) / 审计列`。
`scene` 区分导出场景（前端 `storageKey`：`statistics`、`groupStat`、`statisticsDetail-company`、`customer-bound-company`…）。

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| GET | `/admin/recruitment/export-template/list` | `scene` | `R<List<RecExportTemplate>>`（仅公共模板） |
| POST | `/admin/recruitment/export-template` | `{scene, name, config}` | `R<RecExportTemplate>`（按 租户+scene+name upsert） |
| DELETE | `/admin/recruitment/export-template/{templateId}` | — | `R<Void>` |

## 2. 后台异步导出 + 站内信通知（大数据量）

前端在「筛选数据 > 10000 条」时已弹二次确认，目前只提供「同步导出」。后端就绪后增加「后台异步导出」分支：把当前**筛选条件 + 列配置快照**提交到服务端，由服务端生成文件，完成后站内信通知。

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| POST | `/admin/recruitment/export-task` | `{scene, query(原始分页查询条件), config(配置快照)}` | `R<{taskId}>` |

- 服务端按 `scene` 复用既有 list 查询（company-detail / user-detail / sea-customer / group-statistics 等）拉全量。
- 按 `config` 渲染列/列名/拆分 Sheet/合计/格式，生成 xlsx 落到 OSS。
- 完成/失败发站内信（复用现有通知体系），附下载链接。

> 前端接线：在二次确认里新增「后台异步导出」按钮 → 调该接口 → toast「已提交，完成后站内信通知」。

## 3. 导出记录 / 历史文件（7 天）

弹窗角落可加「导出记录」入口，查看历史异步导出文件并下载（保留 7 天）。

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| GET | `/admin/recruitment/export-task/list` | `pageNum/pageSize/scene?` | `TableDataInfo<{taskId, scene, fileName, status(处理中/成功/失败), rowCount, fileUrl, createTime, expireTime}>` |

- `status`：0 处理中 / 1 成功 / 2 失败。
- `fileUrl`：成功且未过期时给 OSS 临时下载地址；过期置空。
- 建议落表 `rec_export_task` 并定时清理 7 天前文件。

## 配置快照 JSON（前端 snapshot 结构，供模板 config / 异步任务 config 落库）

```jsonc
{
  "cols": [ { "key": "name", "label": "推广人", "visible": true, "width": 12 } ], // 顺序即导出顺序；label 为自定义表头；width 字符数(留空自适应)
  "splitBy": "identity",          // 拆分维度 value；"none" 不拆
  "includeTotals": true,           // 合计行
  "totalKeys": ["companyCount"],  // 参与求和的数值列；空=全部数值列
  "totalLabel": "合计",
  "includeSummary": true,          // 多 Sheet 时的汇总目录页
  "thousands": false,              // 数字千分位
  "autoFilter": false,             // Excel 自动筛选器
  "watermarkOn": false,            // 导出时间/操作人/备注
  "watermarkText": "",
  "desensitize": true,             // 手机号等敏感字段脱敏
  "exportFormat": "xlsx"          // xlsx | csv
}
```

> 注意：当前**前端独立**实现了 xlsx 渲染（SheetJS）。异步导出落到后端后，后端需按同一份 config 语义渲染，二者口径要对齐（尤其拆分 Sheet 命名、合计行、脱敏规则）。
